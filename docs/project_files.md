# Project Files

| File | Purpose |
|---|---|
| data/sample_sales_margin_data.csv | Sample transaction-level sales and cost dataset |
| src/avg_gross_margin.py | Python script that validates inputs, calculates gross margin, creates summaries, and exports outputs |
| outputs/margin_detail.csv | Transaction-level gross margin calculations |
| outputs/gross_margin_summary.csv | Average gross margin by product, customer, region, and month |
| outputs/data_quality_issues.csv | Records with missing, duplicate, zero, negative, or questionable input values |
| outputs/margin_flags.csv | Transactions requiring margin performance review |
| docs/project_summary.md | Business-facing explanation of what the project demonstrates |
| docs/run_instructions.md | Instructions for running the analysis in a Python environment |
